About AlzheimerCare

AI-Based Alzheimer's Disease Detection System

🧠 About the Project

Alzheimer's disease is a progressive neurological disorder that primarily affects memory, thinking, behaviour and other cognitive abilities.

This project aims to develop an Artificial Intelligence based system for classifying MRI brain images into different Alzheimer's disease stages.

A deep learning model is integrated with a Django web application. Users can upload an MRI image and receive the classification generated by the trained machine learning model.

🧠

AI + Healthcare

Combining deep learning and medical image analysis to support research in Alzheimer's disease detection.
